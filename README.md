# Student Performance Analysis Using Google Sheets

## Project Overview
This beginner data analytics project explores student marks across Mathematics, Science, and English using Google Sheets.

## Objectives
- Organize and analyze student marks.
- Calculate total and average marks.
- Classify students based on their average marks.
- Identify students who may need improvement.
- Compare subject performance using a chart.

## Tools Used
- Google Sheets
- Spreadsheet formulas
- Data sorting and filtering
- Column charts

## Skills Practiced
- Data organization and cleaning
- SUM and AVERAGE formulas
- IF statements
- Sorting and filtering
- Data visualization
- Writing analytical findings
